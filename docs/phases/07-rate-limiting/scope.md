# Scope

이 문서는 기본 템플릿이다. Phase 성격에 따라 섹션을 추가하거나 삭제할 수 있다.

## Target

- Fixed Window
- Sliding Window
- Token Bucket
- 경계 조건과 메모리 비용

## Out of Scope

- JWT Blacklist
- Session Management
- 인증 정책 설계

## Completion Gate

- [ ] Fixed Window 경계 조건 문제를 재현했다.
- [ ] Sliding Window와 Token Bucket 결과를 비교했다.
- [ ] Redis key count와 memory usage를 기록했다.
- [ ] report에 알고리즘 선택 기준을 기록했다.
