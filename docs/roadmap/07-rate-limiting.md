# Phase 7. Rate Limiting

## Goal

Redis 자료구조 기반 rate limiting 알고리즘을 비교한다.

## Targets

- Fixed Window
- Sliding Window
- Token Bucket

## Completion Criteria

- Fixed Window 경계 조건 문제를 재현한다.
- Sliding Window와 Token Bucket의 정확도/메모리 비용을 비교한다.
- 인증 프로젝트와 겹치지 않도록 보안 정책보다 알고리즘/Redis 자료구조 중심으로 정리한다.
