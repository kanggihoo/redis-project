@README.md README.md 내용은 전체 프로젝트 개요이며 현재 phase1 내용은 완료했고 이제 phase2(Stampeding Herd 해결 및 특수 자료구조 적용) 에 대한 구현계획을 작성을 해줘. 만약에 아래 내용에 대해 궁금한사항이나 최종 확인이 필요하면 먼저 물어본뒤 모호성을 해결한뒤에 구현계획을 작성해줘

모든 코드 작성은 TDD(Testcontainers) 방식으로 검증하며 다음 TDD 규칙을 준수해야함.

## TDD 규칙

1. **껍데기 먼저** → 2. **실패 테스트(Red)** → 3. **최소 구현(Green)** → 4. **리팩토링**

- 구현 없이 테스트 먼저 작성 금지 (import 에러 = Red 아님)
- 각 단계마다 실행해서 결과 눈으로 확인

또한 필요한 gradle의 의존성은 사용자가 직접 할 예정이니 필요한 의존성은 맨 위에 작성을 해줄 수 있도록 하고, 실제 코드 구현시에는 의존성 모두 준비되어있다고 가정한채로 구현을 해주면됩니다. (필요한 docker-compse , k6 관련 스크립트는 작성해주어야함.)
